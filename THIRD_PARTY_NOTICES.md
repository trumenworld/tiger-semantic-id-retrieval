# Third-party notices

## NonameUntitled/tiger

The `src/tiger` implementation contains modified portions of
[NonameUntitled/tiger](https://github.com/NonameUntitled/tiger), released under
the MIT License. The original copyright notice is preserved in
`licenses/NonameUntitled-tiger-MIT.txt`.

The current repository adds experiment-specific configurations, the RQ-OPQ
SID utilities, and the GPU prefix-table logits processor. The training and
evaluation code remains clearly attributed so the comparison is auditable.

## TIGER paper

The method is described in *Recommender Systems with Generative Retrieval*,
NeurIPS 2023, by Rajput et al. Please cite the paper when using the method.
